# Service design

Public root: `/odata/v4/it-operations/`. Namespace: `ITOperations`.
Future service: `ZUI_IT_OPERATIONS`, OData V4 UI binding `ZUI_IT_OPERATIONS_O4`.
[Entity names](../data-model/entities.md) and [RAP mapping](../rap/baseline.md) are the
baseline. Phase 1 metadata under `mock/` is a minimal preview fixture. Phase 2 defines
complete navigation, types, annotations, actions and representative data.
